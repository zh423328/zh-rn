# zh-rn

创建一个符合中文开发习惯的 React Native 项目脚手架。

基于 Expo SDK 58（React Native 0.88 · New Architecture）+ Expo Router v7（文件式路由）+ NativeWind v5（Tailwind CSS v4）+ Zustand。

## 快速开始

```bash
# 交互式创建
npx @zayn919/create-zh-rn

# 非交互创建（默认 base 模板）
npx @zayn919/create-zh-rn my-rn-app
```

```bash
cd my-rn-app
pnpm i
pnpm start
```

详细说明见 [RN.md](./RN.md)。
